# DevPath

DevPath یک اپ برای برنامه‌ریزی و پیگیری یادگیری برنامه‌نویسی است. مسیر ۲۶ هفته‌ای آن، بک‌اند با Go، هوش مصنوعی و مبانی سیستم‌ها را به درس، تمرین و پروژه تقسیم می‌کند. می‌توانی برنامه مطالعه‌ات را تنظیم کنی، زمان و پیشرفتت را ثبت کنی و با یک حساب، روی دستگاه‌های مختلف ادامه بدهی.

[بازکردن وب‌اپ](https://arshiaamirabadi-ui.github.io/devpath/) · [دانلود اندروید](https://github.com/arshiaamirabadi-ui/devpath/releases/latest) · [انتشارها](https://github.com/arshiaamirabadi-ui/devpath/releases)

## امکانات

- مسیر یادگیری ۲۶ هفته‌ای با حدود ۳۹۰ ساعت محتوای برنامه‌ریزی‌شده.
- راهنمای فارسی درس‌ها، منابع مشخص، تمرین و معیار بررسی نتیجه.
- برنامه روزانه و تقویم مطالعه با هدف هفتگی قابل تنظیم.
- ثبت وضعیت فعالیت‌ها، زمان مطالعه و شواهد تمرین و یادگیری.
- ۱۲ پروژه با چک‌لیست تحویل، توضیح مراحل و پیوند به درس‌های مرتبط.
- کتابخانه منابع، پیگیری مهارت‌ها، یادداشت و مرور هفتگی.
- نقشه تعاملی موضوع‌ها و پیش‌نیازها، نمودار پیشرفت و سفر تصویری ادیسه.
- رابط فارسی و انگلیسی، پشتیبانی از راست‌به‌چپ و چپ‌به‌راست، تم روشن و تاریک.
- ساخت حساب و ورود با ایمیل و رمز عبور، بازیابی رمز و سینک بین دستگاه‌ها.
- استفاده آفلاین پس از بارگذاری اولیه و نگهداری تغییرها تا اتصال دوباره.
- خروجی JSON و بازیابی پشتیبان با پیش‌نمایش تغییرها.

## شروع استفاده

۱. [وب‌اپ](https://arshiaamirabadi-ui.github.io/devpath/) را باز کن یا نسخه اندروید را از [آخرین انتشار](https://github.com/arshiaamirabadi-ui/devpath/releases/latest) بگیر.
۲. در تنظیمات، تاریخ شروع، روزهای مطالعه و هدف ساعت هفتگی را انتخاب کن.
۳. از برنامه امروز یا نقشه راه وارد درس شو و پیشرفتت را ثبت کن. بازکردن یک درس، آن را خودکار تکمیل نمی‌کند.
۴. برای ادامه روی دستگاه دیگر، در بخش «حساب و سینک دستگاه‌ها» وارد همان حساب شو.

استفاده در حالت مهمان هم ممکن است. اگر قبلاً بدون حساب کار کرده‌ای، گزینه «انتقال داده‌های مهمان» را بزن و پیش‌نمایش را بررسی کن تا اطلاعات به حسابت منتقل شوند.

## وب، اندروید و آیپد

**وب:** در مرورگر دسکتاپ، موبایل و تبلت از همان [نشانی برنامه](https://arshiaamirabadi-ui.github.io/devpath/) استفاده کن.

**اندروید:** فایل APK امضاشده و فایل بررسی SHA-256 در [صفحه انتشار](https://github.com/arshiaamirabadi-ui/devpath/releases/latest) قرار دارند. نسخه جدید را می‌توان روی نسخه قبلی نصب کرد. در APK فعلی، ورود با ایمیل و رمز عبور در دسترس است؛ ورود مستقیم گوگل در اندروید هنوز فعال نیست.

**آیپد:** برنامه را در Safari باز کن و از منوی Share گزینه **Add to Home Screen** را بزن. اگر **Open as Web App** نمایش داده شد، آن را روشن نگه دار. بار اول اجازه بده بارگذاری کامل شود تا درس‌ها و فایل‌های برنامه برای استفاده آفلاین آماده شوند.

منابع و پیوندهای بیرونی و ورود به حساب به اینترنت نیاز دارند.

## حساب، سینک و پشتیبان

اطلاعات هر حساب بین دستگاه‌هایی که با همان حساب وارد شده‌اند سینک می‌شود. تغییرهای آفلاین ابتدا روی دستگاه ذخیره و بعد از اتصال ارسال می‌شوند. اگر یک مورد روی دو دستگاه تغییر کرده باشد، برنامه هر دو نسخه را نگه می‌دارد تا نسخه موردنظر را انتخاب کنی.

داده مهمان جدا از حساب است و خودکار آپلود نمی‌شود. خروج از حساب، فضای مهمان را برمی‌گرداند؛ کش حساب و تغییرهای ارسال‌نشده روی دستگاه باقی می‌مانند تا با ورود دوباره به همان حساب ادامه پیدا کنند.

در بخش تنظیمات می‌توانی پشتیبان JSON بگیری یا فایل قبلی را بازیابی کنی. بازیابی و بازنشانی در حالت ورود، به حساب و دستگاه‌های دیگر هم منتقل می‌شوند؛ پیش از تأیید، پیش‌نمایش را بررسی کن.

## نگهداری داده‌ها

- داده مهمان روی همان مرورگر یا اپ ذخیره می‌شود.
- داده حساب برای احراز هویت و سینک از Firebase Authentication و Cloud Firestore استفاده می‌کند.
- دسترسی ابری بر اساس شناسه حساب محدود می‌شود تا هر کاربر به اطلاعات خودش دسترسی داشته باشد.
- Analytics در این نسخه فعال نیست.
- پاک‌کردن داده سایت یا اپ می‌تواند داده مهمان و تغییرهای سینک‌نشده را حذف کند. اطلاعاتی که قبلاً سینک شده‌اند با ورود دوباره دریافت می‌شوند.

## اجرا برای توسعه

با Node.js سازگار با وابستگی‌های پروژه، از پوشه مخزن اجرا کن:

```sh
npm ci
npm run dev
```

نشانی سرور توسعه در خروجی ترمینال نمایش داده می‌شود. دستورهای بررسی و ساخت:

```sh
npm test
npm run build
npm run test:e2e
```

برای استفاده از پروژه Firebase دیگر، تنظیمات نمونه `.env.example` را در `.env.local` قرار بده و Authentication، Firestore و قوانین دسترسی آن پروژه را تنظیم کن. اطلاعات مدیریتی و کلید خصوصی نباید در کد کلاینت یا مخزن قرار بگیرند.

فناوری‌ها: React، TypeScript، Vite، Capacitor و Firebase. [مشخصات سینک](SPEC-account-sync.md) و [گزارش بررسی‌ها](VERIFICATION.md) جزئیات پیاده‌سازی و محدودیت‌های آزموده‌شده را توضیح می‌دهند.
