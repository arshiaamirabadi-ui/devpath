# DevPath

ابزار شخصی فارسی و RTL برای اجرای رودمپ یادگیری Go Backend، AI و سیستم‌ها. با React، TypeScript و Vite ساخته شده و برای کارکرد اصلی حساب کاربری، بک‌اند یا API هوش مصنوعی لازم ندارد.

## اجرا

Node.js نسخه ۲۰٫۱۹ به بالا یا ۲۲٫۱۲ به بالا نصب باشد.

```powershell
cd 'D:\Devpath GPT\rahgo'
npm ci
npm run dev -- --port 5187 --strictPort
```

نشانی محلی: http://127.0.0.1:5187

```powershell
npm run build
npm test
npm run test:e2e
```

تست مرورگر به Microsoft Edge و سرور اجراشده روی پورت ۵۱۸۷ نیاز دارد. پروفایل تست جداست. در سیستم بدون Edge، channel را در playwright.config.ts تغییر بده و مرورگر مناسب Playwright را نصب کن. روی Windows اگر Vitest هنگام نوشتن Temp خطای EPERM داد:

```powershell
New-Item -ItemType Directory .temp -Force
$env:TEMP=(Resolve-Path .temp).Path
$env:TMP=$env:TEMP
npm test
```

خروجی تولید در dist قرار می‌گیرد و روی میزبان استاتیک قابل اجراست. مسیریابی hash است و به rewrite سمت سرور نیاز ندارد. npm run dev برای توسعه است؛ برای اجرای محلی خروجی تولید از `npx vite preview --host 127.0.0.1 --port 5187` استفاده کن.

## قابلیت‌ها

- داشبورد با آمار واقعی، برنامه امروز، عقب‌مانده‌ها و ادامه فعالیت
- شش ماه و ۲۶ هفته، ۱۵۶ فعالیت اجباری و یک آزمایش CUDA اختیاری
- نقشه دیاگرامی با ۴۲ گره کلیک‌خور، پیش‌نیازها، ارتباط‌های مستقیم، جست‌وجو و بزرگ‌نمایی
- تغییر وضعیت، سه شاهد مطالعه/تمرین/توضیح، برنامه‌ریزی روزها، ثبت و اصلاح نشست
- ۱۲ پروژه با معیار پذیرش، چک‌لیست و لینک‌های مخزن/دمو/مستندات
- ۱۹ منبع با جست‌وجو، فیلتر، نشان‌کردن و وضعیت مطالعه
- ۳۰ مهارت با سطح و شاهد جدا برای هر سطح
- یادداشت مرتبط با فعالیت، هفته، پروژه و یادداشت عمومی؛ مرور هفتگی قابل ویرایش
- تم روشن/تاریک، تقویم شنبه‌محور و تاریخ شمسی با منطقه تهران
- خروجی JSON، اعتبارسنجی کامل ورودی، پیش‌نمایش دامنه جایگزینی و تأیید بازیابی

## ساختار و تصمیم‌ها

`src/content.ts` محتوای ثابت است؛ شناسه‌های فعالیت، منبع، هفته و پروژه با تغییر عنوان عوض نمی‌شوند. `src/graph.ts` ارتباط‌های پیشنهادشده میان مهارت‌ها و پروژه‌ها را تعریف می‌کند. دیاگرام و فهرست هفته‌ها داده پیشرفت یکسان را می‌خوانند؛ پیشرفت درس، پروژه و تسلط مستقل‌اند.

`src/logic.ts` محاسبه زمان، پیشرفت، زمان‌بندی و شِمای Zod را نگه می‌دارد. `src/store.tsx` نوشتن اتمی localStorage و همگام‌سازی رویداد storage میان زبانه‌ها را انجام می‌دهد. ذخیره هم‌زمان، آخرین نسخه مرورگر را پیش از تغییر می‌خواند. تایمر ساخته نشده و زمان فقط دستی ثبت می‌شود؛ اصلاح نشست با همان شناسه، جایگزین می‌شود.

برای داده متنی کم‌حجم این نسخه، localStorage از IndexedDB ساده‌تر است و نوشتن همگام آن پیش از اعلام موفقیت پایان می‌یابد. خطای ظرفیت/دسترسی به کاربر گزارش می‌شود و وضعیت جاری در حافظه باقی می‌ماند. کل داده شخصی نسخه ۱ دارد و محتوای آموزشی جداست. افزودن فیلدهای اختیاری سازگار است؛ تغییر ناسازگار بعدی به مهاجرت داده نیاز دارد.

پیشرفت وزنی، دقیقه تخمینی فعالیت اجباری انجام‌شده تقسیم بر کل دقیقه اجباری است. آیتم مشترک با شناسه یکسان یک بار شمرده می‌شود؛ فعالیت اختیاری در مخرج نیست. زمان واقعی از مجموع نشست‌ها می‌آید. ۲۶ هفته محتوایی × ۱۵ ساعت = ۳۹۰ ساعت؛ کاهش هدف هفتگی مدت تقویمی را افزایش می‌دهد. هر فعالیت می‌تواند سهمی در چند روز داشته باشد؛ تاریخ دستی، کل فعالیت را به یک روز می‌برد. این انتخاب عمدی برای ساده نگه‌داشتن برنامه‌ریز نسخه اول است.

مرز اعتماد فایل JSON و متن کاربر است: حجم حداکثر ۵ مگابایت، شِمای کامل، تاریخ/مقادیر/شناسه‌های تکراری و URL غیر http(s) بررسی می‌شوند. React متن را escape می‌کند؛ HTML یادداشت اجرا نمی‌شود. پیش از بازیابی هیچ تغییری اعمال نمی‌شود. فونت Vazirmatn همراه برنامه میزبانی می‌شود؛ هیچ فونت، telemetry یا داده شخصی به سرویس ثالث ارسال نمی‌شود. منابع خارجی با کلیک کاربر در زبانه تازه باز می‌شوند.

## پوشش محتوا

| بخش رودمپ | محل |
|---|---|
| Go، Python، منطق دیجیتال | ماه ۱، هفته ۱ تا ۴ |
| HTTP، Gin، SQL، هویت، CPU و ML | ماه ۲، هفته ۵ تا ۸ |
| تست، هم‌زمانی، Docker، حافظه، PyTorch و MNIST | ماه ۳، هفته ۹ تا ۱۲ |
| رابط وب، React، TypeScript، CPU و GPU | ماه ۴، هفته ۱۳ تا ۱۶ |
| Transformer، آموزش، Fine-tuning و CPU/GPU | ماه ۵، هفته ۱۷ تا ۲۰ |
| StudioFlow، C، استقرار، مستندات و رزومه | ماه ۶، هفته ۲۱ تا ۲۴ |
| رفع نقص، ارزیابی نهایی و پورتفولیو | هفته ۲۵ و ۲۶، پیشنهاد تکمیلی |
| منابع، ابزارها، اصلاح‌ها و مسیرهای تخصص بعدی | کتابخانه و راهنمای مسیر |

هفته‌های ۲۵ و ۲۶، تمرین‌های دقیق، معیارها، پرسش‌ها، زمان‌بندی جزئی و روابط دیاگرام پیشنهاد تکمیلی‌اند. موضوع‌ها و منابع اصلی حفظ شده‌اند. متن نام فرستنده، زمان پیام، Worked for، ارجاع خراب، utm و تصاویر موقت حذف شده است. فرض بهترشدن مدل در هر Epoch اصلاح شده؛ RTX 3060/6GB مشخصات قطعی کاربر فرض نشده است. StudioFlow پروژه آموزشی داخل مسیر است.

عنوان و بازشدن ۱۹ صفحه منبع در ۲۰۲۶-۱۱-۱۴ بررسی شد؛ دسترسی آینده، تغییر نسخه مستندات و کامل‌بودن ترجمه تضمین نیست. صفحه قدیمی CS:APP اعلان جابه‌جایی دارد؛ یادداشت آن در کتابخانه حفظ شده است. زمان‌بندی مطالعه گزینشی است و پایان تمام کتاب‌ها را لازم نمی‌داند.

## بررسی‌ها و محدودیت‌ها

تست‌های واحد منطق، زمان‌بندی، ساعت کل، شناسه‌ها، ارجاع منابع، بازیابی و گراف را پوشش می‌دهند. تست مرورگر گردش کامل تکمیل/زمان/یادداشت/رفرش/خروجی/بازیابی، تمام ۲۶ هفته، منابع، پروژه، مرور، مهارت، نمایش ایمن متن، موبایل و دیاگرام را بررسی می‌کند. تصاویر بررسی در test-results ساخته می‌شوند.

این نسخه شخصی و محلی است: همگام‌سازی ابری، حساب چندکاربره و اجرای آفلاین پس از پاک‌شدن کش ندارد. داده هر origin مرورگر جداست؛ برای انتقال میان پیش‌نمایش و سایت منتشرشده باید خروجی/بازیابی انجام داد. پاک‌کردن داده سایت یا محدودیت حالت خصوصی می‌تواند داده را حذف کند. فضای localStorage محدود است و خطای پرشدن نمایش داده می‌شود؛ پشتیبان منظم لازم است. محتوای آموزشی قابل پیگیری است و تصحیح خودکار تمرین یا تضمین تسلط/استخدام ندارد.
